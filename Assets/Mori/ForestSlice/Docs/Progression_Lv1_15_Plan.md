# 《深山末日开荒》主角星级 Lv.1 → Lv.15 完整成长数值与新手引导策划案

> **设计定位**：对标《向僵尸开炮》外围养成节奏 ×《Whiteout Survival（无尽冬日）》/《Water World》双轨人口与工坊订单经济闭环。
> **核心原则**：
> 1. **1~15 级平滑解锁**：每升 1 级固定解锁 **2~4 项高感知新内容**（新建筑 / 建筑升阶上限 / 新工坊配方 / 骨干英雄或委任槽），既避免前期一次性塞入过多系统造成认知过载，也杜绝中后期“空等级”。
> 2. **严格零死锁（Zero-Deadlock DAG）**：任意建筑在 `Lv.K` 解锁建造或升阶时，其所需的【前置材料生产工坊与配方】、【当前实有人口 `reqPopCur`】、【供暖人口上限 `reqPopCap`】以及【单品仓库容量上限 `StorageCap`】100% 均已在 `<= Lv.K` 解锁且可自循环产出。特别修复原版“锯木坊 Lv.3 需铁锭 ↔ 锻造坊 Lv.2 需承重梁”的互锁问题（调整为锯木坊 Lv.3 仅需厚木板+铁钉即可产出承重梁，再支撑锻造坊 Lv.2 冶炼铁锭）。
> 3. **战斗预留 ~20% 加速弹性（绝不强制卡基建）**：纯种田基建玩家仅靠【林地拓荒 + 农牧自循环 + 四维居民订单 + 5单宝箱 + 升星奖励 + 山口行商】即可获得充足经验、工程手稿、医疗电子件与英雄勋章直达 Lv.15 满阶；山口尸潮波次迎击与丧尸城开车搜刮提供约 **20% 经验与稀有手稿/勋章/黄金良种加速空间**，体验爽快而不逼氪逼肝。
